# 操作マニュアル

## はじめての試聴

1. このPCでVOICEVOXかAivisSpeechを起動します。
2. 「はじめての試聴・接続を確認する」を開きます。接続確認だけでは音声を生成しません。
3. 未接続ならアプリの起動と接続設定を、接続済みで候補がない場合は話者・スタイル・モデルを確認します。起動後は「試聴用の接続を再確認」を押してください。
4. 「はじめての試聴の声」とセリフを選び、「最初の試聴音声を生成」を押します。
5. 再生ボタンで確かめ、必要に応じてWAVを保存します。セリフや声を変更すると、変更前の音声は消えます。

AIのAPIキーは不要です。この欄での試聴は声の採用やライブラリ登録にはなりません。比較するときは「VOICEVOX・AivisSpeechを比較する」を開いてください。

## 作品を保存して別の環境で再開する

「作品を保存・復元する」を開き、作品名を入力します。

- **作品をブラウザに保存**：声探し・製品比較・採用声・保存設定の比較・キャスティング表・編集中の台本・台本ライブラリをまとめて保存します。台本の個別保存を押していない編集内容も含みます。
- **作品JSONを書き出す**：現在の作業一式をJSONでダウンロードします。ブラウザ保存とは別の操作で、ブラウザの保存容量が足りない場合も書き出せます。
- **作品JSONを読み込む**：形式と容量を確認し、作品名・登録数・台本行数を表示します。「確認した作品を復元」で現在の作業を切り替えます。キャンセルすれば変更しません。

別のブラウザ環境では同じアプリを起動し、作品JSONを読み込んでください。ブラウザ内には最大20作品を保存できます。「作品ライブラリ」から作品名の検索・新規作成・切り替え・名前変更・保存済み作品の複製・削除ができます。切り替え時に未保存の変更がある場合は「保存して作品を切り替える」「未保存の変更を破棄して切り替える」「作品の切り替えをキャンセル」を選びます。保存と切り替えは同時に反映し、失敗時は元の作業を保持します。

作品JSONの取り込みも一覧へ追加します。同じIDの異なる内容は別作品として追加して既存作品を保護します。複製は保存済みの状態から作り、編集途中の状態は先に作品を保存してください。削除は対象作品名を確認してから行い、使用中の作品に未保存の変更がある場合は破棄の確認も行います。最後に使用していた作品の保存済み状態を再起動後に開きます。

作品JSONは32MiB以下、作品ライブラリの設定全体は64MiB以下です。中に含む個別データにも従来の件数・容量制限を適用します。ブラウザの保存容量は環境により異なり、この容量のブラウザ保存を保証する上限ではありません。保存失敗時には作業を切り替えず、既存の作品を保持します。

画像・生成音声・APIキー・一時的な解析結果・評価の集計欄・未登録の名前やメモなどの入力欄はJSONに含みません。キャラクター設定、補足、採用理由、表示用セリフ、読み上げ文、作品の読み方辞書は含みます。外部AIへの送信同意は復元せず、生成も自動実行しません。同じブラウザ内に保存した台本音声は条件が一致すれば再利用できます。

作品をブラウザに保存した後、その作品での個別保存も作品の中へ反映します。従来の個別JSONは引き続き読み込めます。作品保存を始める前のブラウザ内の個別保存は上書きしません。「以前のブラウザ保存を開く」で内容を確認し、新しい作品として呼び出せます。現在の作品を残す場合は、先に作品JSONを書き出してください。

未保存の変更と最終保存日時を表示します。別のタブで作品が更新された場合は上書きを拒否します。現在のタブの編集は作品JSONへ書き出してから、作品を開き直してください。復元は生成・読み込み等の処理が終わってから実行します。

## 音声も含めて作品を持ち運ぶ

「作品を保存・復元する」内の「音声も一緒に持ち運ぶ」を使います。

1. 台本を含む作品をブラウザに保存します。
2. 台本の音声を生成し、「台本音声をブラウザに保存」を押します。複数の台本を移す場合は、台本ライブラリに残した各台本で音声も保存してください。
3. 「音声付き作品アーカイブを書き出す」で`.vaarchive`ファイルをダウンロードします。作品設定は操作開始時の編集中の内容を含み、音声はブラウザ保存済みで条件が一致するものを含みます。書き出し後に含めた音声の行数を表示します。
4. 移動先で「音声付き作品アーカイブを読み込む」からファイルを選びます。作品名・登録数・音声の行数と容量を確認します。この時点では作品と音声を保存しません。
5. 「確認した音声付き作品を復元」で、新しい作品として一覧に追加して開きます。現在の作品に未保存の変更があれば、保存して切り替えるか、破棄して切り替えるかを選びます。キャンセルすれば切り替えません。
6. 復元先で台本を開くと、条件が一致する音声を自動で読み込みます。保存台本へ切り替えた際も音声を再利用できます。復元・再利用で音声生成APIを呼ぶことはなく、エンジン未接続でも再生できます。音声のない行を新しく生成する場合はエンジンが必要です。

対象は編集中の台本と台本ライブラリに残した台本です。同じ行IDでも読み上げ文・話者・調声値が違う場合は、一致する条件だけで音声を再利用します。ブラウザに保存していない試聴音声、条件に一致しない音声、画像、APIキー、結合WAV、声探しや比較欄の試聴音声は含みません。作品JSONの保存形式は従来どおりで、音声は含みません。

1行の音声20MiB、音声合計64MiB、設定ヘッダー33MiB、ファイル全体100MiBまでです。復元先にも作品数20件・設定全体64MiB・保存音声全体128MiB/1000行など、既存のブラウザ保存の上限を適用します。元と同じ作品IDのファイルでも新しいIDで追加するため、既存作品の設定・保存音声を上書きしません。

音声の破損、未対応の形式・版、容量不足、別タブによる更新では復元を拒否します。音声の保存中に現在の編集が変わった場合も切り替えず、編集内容を保持します。「アーカイブの処理を中止」でも中止できます。音声保存の途中の場合はその処理の終了後に中止を反映し、一時保存した音声を後片付けします。

## 台本の表記と読み上げ文

台本の各行で「読み上げ文を別に指定」をオンにすると、表示するセリフとは別に、実際に音声エンジンへ渡す文章を1〜300文字で指定できます。例：セリフは「星詠みの塔」、読み上げ文は「ほしよみのとう」。空白だけの読み上げ文では生成・保存できません。

別の読み上げ文を指定している間、表示用セリフだけの変更では行の音声を保持します。読み上げ文・話者・調声値が変わると、その行の音声を無効にします。読み上げ文は台本・台本ライブラリ・作品JSONに保持し、結合WAVの出力記録にも実際の読み上げ文を記録します。旧台本に指定がなければ従来どおりセリフを読み上げます。

## 作品の読み方辞書

台本欄の「作品の読み方辞書」を開き、表記と読み方を登録します。最大100件で、同じ表記の重複はできません。辞書は作品ごとに分かれ、作品のブラウザ保存・JSONに含まれます。入力途中で辞書に反映していない内容は保存しません。

「辞書を適用する行を確認」で変更対象と読み上げ文をプレビューし、「確認した読み方を台本に反映」で適用します。プレビュー後に台本や辞書が変わった場合は確認し直します。長い表記を優先し、置換した結果を続けて置換しません。行ごとに手動指定した読み上げ文は保持します。

辞書は音声エンジンに辞書をインストールする機能ではなく、台本の読み上げ文へ反映する機能です。辞書を編集・削除した後は対象を再確認して適用してください。辞書から作った読み上げ文の行で表示用セリフを変更すると、その読み上げ文を解除するので、必要に応じて再適用します。読み上げ文を直接編集すると手動指定として扱います。音声条件が変わった行だけ再生成が必要です。

## 台本音声の保存と再利用

1. 現在の台本を含む作品をブラウザに保存します。
2. 台本の音声を生成し、「台本音声の保存と再利用」を開きます。
3. 「台本音声をブラウザに保存」で、現在の条件に対応する生成済み音声を保存します。未保存の台本がある場合は先に作品を保存します。
4. 再起動して同じ作品の台本を開くと、作品ID・行ID・読み上げ文・話者・調声値が一致する保存音声を自動で読み込みます。音声生成APIは呼びません。「保存した台本音声を読み込む」から再確認もできます。

音声はこのブラウザのIndexedDBに保存し、作品JSONへ含めません。別ブラウザへ音声も移す場合は音声付き作品アーカイブを使います。作品一覧の複製には音声を含めません。保存時の生成情報も保持するため、表示されるエンジン版はその音声を生成した当時の値です。現在のモデルやエンジンで作り直す場合は、行の再生成を使ってください。

1行20MiB、1作品64MiB、全作品128MiB・1000行までです。上限・保存容量・ブラウザ設定による失敗では、現在の試聴音声と既存の保存音声を保持します。「この作品の保存音声を削除」「全作品の保存音声を削除」は確認後に保存音声だけを消し、編集中の音声・台本・声の設定は保持します。作品の削除時にも対応する保存音声の後片付けを行います。

## 最初の候補を探す

1. `npm ci` → `npm run dev` で起動し、`http://127.0.0.1:3210` を開きます。
2. 「提案の作り方」で「手動」を選び、4つのスライダーを調整します。画像・APIキーは不要です。「まずは、こんな声から」のプリセットでも始められます。
3. 「このイメージで声を探す」を押します。候補を出した後は、4軸の変更に合わせて順位が更新されます。
4. ソフトの絞り込みや「無料のみ」「試聴可能のみ」を使い、候補カードを選んで詳細を比較します。該当する候補がないときは「絞り込みをリセット」で戻せます。

カタログは16話者・24候補です。VOICEVOXは12話者・20候補を収録し、同じ話者でもスタイルが違えば別候補になります。詳細の「話者・スタイルの出典」で公式資料と確認日を確認できます。4軸の数値は未校正の編集値で、実機での聴取評価は未実施です。

順位とスコアは希望する演出とカタログの編集値の近さです。実際の声との一致率ではありません。「無料のみ」は音声の用途に関する許諾を保証しません。

## スライダーとヘルプ

各項目の「?」へマウスを合わせるか、タップすると説明を表示します。キーボードでは Tab でヘルプへ移動して表示し、Escape で閉じます。外側のクリックでも閉じられます。

| 項目     | 小さい値 → 大きい値   | 使い方                   |
| -------- | --------------------- | ------------------------ |
| 声の高さ | 低め → 高め           | 候補となる声の方向を選ぶ |
| 活発さ   | 静か → 活発           | 語りの勢いを選ぶ         |
| 柔らかさ | シャープ → 柔らかい   | 響きの印象を選ぶ         |
| 息の多さ | 張りがある → 息を含む | ささやきなどの演出を探す |

この4軸は候補の推薦に使います。選んだ話者の音声合成値は、詳細にある「調声レシピ」で別に調整します。

## 画像から演出案を作る

1. 一人の人物・キャラクターのPNG・JPEG・WebP静止画を選ぶか、ドロップします。上限は8MB・25メガピクセルです。
2. Ollama・OpenAI・Claude・Geminiのいずれかを選びます。起動・キー設定の手順は[READMEの接続設定](../README.md#起動)を参照してください。
3. 任意の「演出の補足」に、役割・話し方などの希望を書きます。
4. 外部APIを使う場合は、表示された送信先への画像・補足の送信に同意します。送信先を切り替えると同意はリセットされます。
5. 「画像から声の演出案を作る」を押し、結果と候補を確認します。4軸を変更して演出を調整できます。

画像から本人・声優・実際の声を特定する機能ではありません。対象が複数ある画像や声を当てる対象のない画像では、別の画像を案内する場合があります。

手動では画像をサーバーへ送信しません。AI解析では画像をサーバーで縮小・向き補正・メタデータ除去・JPEG変換して選択した解析先へ送ります。再読み込みでは画像・一時的な解析結果・未保存の音声が消え、保存した作品の設定と文章は復元されます。明示的にブラウザ保存した台本音声は、条件が一致すれば再利用できます。

## 画像なしのキャラクター設定から探す

1. 「入力するもの」で「設定テキストのみ」を選びます。
2. 「キャラクター設定」に役柄・性格・背景・話し方など、作者が決めた設定を2000文字以内で書きます。例：「旅人を案内する司書。穏やかだが芯が強い。丁寧な言葉遣いで話す」。
3. Ollama・OpenAI・Claude・Geminiのいずれかを選び、必要なら「演出の補足」に声の高さ・テンポなどの希望を1000文字以内で書きます。
4. 外部APIでは「キャラクター設定と補足」の送信に同意し、「設定から声の演出案を作る」を押します。入力元や設定・補足・解析先を変えると同意は解除されます。
5. 設定に基づく演出案と4軸を確認し、必要に応じて調整して、候補比較・試聴へ進みます。設定が不足しているときは追記を案内します。

画像は不要です。「画像と設定」に読み込んだ画像が残っていても、テキストのみの送信には含めません。AIには作者が書いた設定を使うよう指示し、画像の特徴を見たような説明をしないようにしています。Ollamaはローカルのテキスト生成対応モデルでも利用でき、画像入力には画像対応モデルが必要です。外部AIには既存の設定モデルを使います。

「画像と設定」でも同じ設定欄を使えます。作者の設定を優先し、画像は視覚的な演出の参考とします。手動モードは画像・設定をAIへ送信せず、文章を自動解釈もしません。設定の意図は4軸に手動で反映してください。

設定や補足を編集しても、現在の4軸・調整値・音声は自動では変更しません。「声の方向を作ったときの設定」から、その4軸に対応する入力を確認できます。入力が変わっている場合は案内を表示し、反映するには演出案の再作成、または4軸の手動調整と検索を行います。比較評価には、その声の方向を作ったときの設定を記録します。レシピJSONには編集中の入力と4軸に対応する入力を別々に保存し、復元後も区別します。

設定・補足は保存JSONや評価CSVに含まれます。画像・APIキーは含みません。旧JSONに設定がなければ空欄で復元し、過去の評価に設定を補いません。

## 試聴と調声

VOICEVOXをこのPCで起動し、画面の「接続設定」から接続を再確認してください。候補の中からVOICEVOXの話者を選ぶと、次の6項目を調整できます。

候補カード・詳細・比較欄には、接続確認時の話者・スタイル一覧に基づく状態を表示します。

| 表示               | 意味・操作                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| 試聴可能           | 接続中のVOICEVOXに、その話者・スタイルがあり、トーク音声の生成対象です                         |
| 未導入             | エンジンには接続できましたが、その話者・スタイルがありません。音声ライブラリを確認してください |
| 未接続             | エンジンまたは話者一覧を確認できません。VOICEVOXの起動と接続設定を確認してください             |
| 確認中             | 話者・スタイルの確認中です。完了まで音声生成はできません                                       |
| アプリ内試聴対象外 | COEIROINK・A.I.VOICE2です。各ソフトの公式サンプル・設定手順を使ってください                    |

「試聴可能のみ」をオンにすると、現在確認できたVOICEVOXの候補に絞ります。ほかのソフト・無料条件との組み合わせで0件になる場合は、条件を変更するか「絞り込みをリセット」を押してください。候補一覧には試聴可能な件数と確認時刻を表示します。エンジン起動・音声ライブラリ追加後は、候補一覧または接続設定の「接続を再確認」を押します。自動で継続監視はしません。

未導入・未接続でも候補ごとの調整とJSON保存はできます。絞り込みや接続の変化で調整値・比較対象・生成済み音声は消えません。比較欄では、選択中の候補を残したまま選択肢を絞ります。比較音声の生成には両候補の「試聴可能」が必要です。新しく比較を始めるときは、試聴可能な候補を優先して初期候補にします。

| 項目     | 範囲         | 意味                         |
| -------- | ------------ | ---------------------------- |
| 話速     | 0.50〜2.00倍 | 大きいほど速い               |
| 音高     | −0.15〜0.15  | 0を基準に声を上下する        |
| 抑揚     | 0.00〜2.00倍 | 大きいほど表情の変化が大きい |
| 音量     | 0.00〜2.00倍 | 1.00を基準に音量を調整する   |
| 開始無音 | 0.00〜1.00秒 | 音声の先頭の無音             |
| 終了無音 | 0.00〜1.00秒 | 音声の最後の無音             |

セリフを300文字以内で入力し、「VOICEVOXで音声を生成」を押します。生成後は音声プレーヤーで確認できます。候補を切り替えても各候補の調整値・音声を保持します。セリフや設定を変更すると、現在の条件と異なる音声は表示されなくなるので再生成してください。「提案値に戻す」は選択中の話者の現在の4軸に対する提案へ戻します。新しい画像を読み込むと、前の調整と比較記録は消えます。

COEIROINK・A.I.VOICE2は「ソフトでの設定手順」と公式サンプルを参照して、各ソフト上で調整します。アプリ内試聴と数値設定には対応していません。

## VOICEVOXとAivisSpeechを比較する

1. このコンピューターで使いたい音声エンジンを起動します。VOICEVOXは既定ポート50021、AivisSpeechは10101です。変更する場合は`.env`の`VOICEVOX_BASE_URL`・`AIVIS_BASE_URL`を編集し、アプリのサーバーを再起動します。
2. ページ上部の「VOICEVOX・AivisSpeechを比較する」を押します。導入済みのVOICEVOXカタログ候補と、AivisSpeechの話者・スタイルを最大200件表示します。新しいモデルを追加したら「比較用の接続を再確認」を押します。
3. 「製品比較候補A」「製品比較候補B」で異なる候補を選びます。同一製品同士、同じ話者の別スタイル、異なる製品の比較ができます。候補の変更で各候補の調整値は消えません。
4. AivisSpeechは「感情表現の強さ」と「テンポの緩急」を調整できます。VOICEVOXの「抑揚」と意味が異なります。AivisSpeechの音高は初期値0で、変更時に音質が低下する場合があります。モデルごとの利用条件・クレジットはAivisSpeechで確認してください。
5. 共通セリフを入力して「製品比較のA・Bを生成」を押します。現在の条件で生成済みの音声は再利用し、部分失敗時は成功した音声を保持します。中止または比較画面を閉じるとブラウザーの待機と残り候補の要求を止めます。エンジンで開始済みの処理は取り消せません。
6. 両候補の音声がそろったら採用結果・理由を入力し、「製品比較の評価を記録」を押します。A/Bの採用で保存対象の声を決めます。評価時の製品・識別情報・調声値・共通セリフ・生成情報・4軸・適用済みキャラクター設定は独立した記録になります。後から調整しても過去の評価は変わりません。AivisSpeechに推薦スコアや順位は付けません。
7. 「比較セッションJSONを保存」で候補別設定・採用した声・比較対象・評価100件までを保存します。「比較セッションJSONを読み込む」で復元できます。最大8MiB、音声・画像・接続先URLは含みません。未導入の候補も復元できますが、再生成にはそのエンジンとモデルが必要です。

この比較セッションは製品を識別する専用形式です。従来のレシピJSON v1/v2/v3は従来の「レシピJSONを読み込む」で引き続き使えます。両画面のセリフ・調声・履歴はそれぞれ保持します。新しい製品比較の履歴は「製品比較の履歴を見る」や「製品比較の履歴を集計する」で確認でき、従来の推薦スコア集計には混ぜません。

## AivisSpeechのモデル情報・利用条件を確認する

製品比較のAivisSpeech候補には「モデル・利用条件」欄があります。接続中のエンジンから取得できたモデル名・モデル版・説明・制作者・利用条件の本文と関連リンク、情報源・確認日時を表示します。「モデル・利用条件を再確認」で再取得できます。取得はローカルエンジンのみで、関連リンクへ自動アクセスしたり、画像や音声サンプルを読み込んだりしません。

利用条件は提供元の文章をテキストとして表示します。MarkdownやHTMLの記法はそのまま表示し、実行・画像表示はしません。クレジットの指定は本文と提供元で確認してください。制作者名をクレジットの必須表記と推定せず、商用利用など用途ごとの可否も自動判定しません。関連リンクは利用条件・制作者の記載から取得できたHTTP/HTTPSのものだけを表示します。

モデル情報が取得できない場合も、比較・音声生成を続けられます。利用条件が記載されていない場合は「記載されていません」と表示します。1候補分の保存情報が上限（UTF-8のJSONで4KiB）を超える場合は本文を掲載せず、「上限を超えるため未掲載」と表示するので、AivisSpeechで全文を確認してください。本文を途中まで切って完全な条件のように表示することはありません。

保存された情報がある候補は、現在の情報と「保存時のモデル情報・利用条件」を分けて表示します。内容の違いがあれば案内を出します。再確認だけでは保存時の情報や過去の評価を上書きしません。

生成済みのAivisSpeech音声には、生成要求時に確認できていたモデル版も表示します。現在表示している情報が異なる場合は、それを案内します。「候補A/Bの音声を再生成」で、その候補だけ新しく生成できます。再生成に成功して現在のモデル情報が取得できていれば、作業中の候補にも新しい確認情報を保持します。評価履歴は書き換えません。モデル情報は確認時点のもので、実際の生成に使われたモデルのハッシュ等を保証するものではありません。

新しい評価には、その試聴音声に対応する確認情報を保存します。生成後に情報を再確認しても、古い音声の評価へ新しい条件を付け替えません。評価時に情報がなかった記録へも後から補いません。比較セッション・集計JSON・CSVで確認時の情報を保持でき、履歴再利用時も当時の情報を残します。比較セッションJSONの上限は情報追加に合わせて8MiBとし、従来のレシピJSONは4MiBのままです。

## 製品比較の履歴をまとめ、採用した声を再利用する

1. 「VOICEVOX・AivisSpeechを比較する」を開き、「製品比較の履歴を集計する」を押します。
2. 「製品比較のJSONをまとめて読み込む」で、複数の比較セッションJSONまたは製品比較の評価JSONを選びます。「現在の製品比較記録を追加」でも作業中の評価履歴を追加できます。いずれも現在の比較候補・調整・音声は変更しません。
3. 判断、比較に含まれる製品、採用した製品、同一/異なる製品の組み合わせ、話者・スタイルで絞り込めます。検索は理由・セリフ・候補名・識別情報・キャラクター設定・補足・エンジン版を対象にします。
4. 「製品比較の集計全体をJSONで保存」は全件、「製品比較の絞り込み結果をCSVで保存」は現在の条件に合う全件を出力します。25件ずつのページ表示に関係なく保存します。評価JSONは後からこの集計へ読み込めます。
5. AまたはBを採用した記録で「この採用声で比較を再開」を押すと、当時の2候補・調声値・セリフを比較欄へ戻し、採用した声を保存対象にします。この2候補で編集中の調整は置き換わります。ほかの候補設定、現在の評価履歴、集計した過去の履歴は保持します。生成済み音声は消すので、再生成してください。
6. 再開した比較では、当時の4軸と適用済みキャラクター設定を次の評価にも記録します。上のキャラクター入力欄は変更しません。「現在の声の方向を次の評価に使う」で、現在の入力側の声の方向へ戻せます。再開時の設定は比較セッションJSONにも保存されます。

集計は最大1000件、一回20ファイル・各32MiB・合計64MiBまでです。日時・順序付き候補と製品別調声値・セリフ・理由・結果・4軸・設定・生成情報が同じ記録を重複として除きます。異なる版や生成情報のある記録と情報のない記録は、それぞれ保持します。不正なJSONや件数超過があれば、その回の追加をすべて取り消します。

現在のカタログから外れたVOICEVOX話者も、当時の名前・設定で履歴を残します。その記録の再開は現在のカタログと照合できないため停止し、編集中の比較を保持します。AivisSpeechの未導入話者は設定を戻せますが、生成には該当エンジンとモデルが必要です。同程度・判断できない記録には採用した声がないため、再開ボタンは無効です。集計から推薦スコアや順位を補うことはありません。

取り込み・集計・再利用はブラウザー内で行います。集計を閉じても保持しますが、ページを再読み込みすると消えるのでJSONで保存してください。CSVには両候補の製品別調声値、UUID/カタログID、取得できたエンジン版・確認日時・観測したスタイルID、理由・セリフ・設定を含めます。CSVの数式解釈を防ぐため、対象の文字で始まるテキストはアポストロフィ付きで出力し、JSONは元の文章を保持します。従来の推薦スコア集計とは別の画面・保存形式です。

## 2候補を比較して声を決める

1. 候補を表示したら「2候補を比較する」を押します。
2. 「候補A」「候補B」で異なるVOICEVOXの話者・スタイルを選びます。同じ話者の「ノーマル」と「ささやき」等も比較できます。各候補の6項目は独立して調整でき、単独試聴の設定にも反映します。
3. 比較するセリフを入力します。単独試聴と共通です。
4. 「A・Bの比較音声を生成」を押します。A・Bを順番に生成します。現在の設定で生成済みの候補は再利用し、片方が失敗しても成功した音声は残します。
5. 両方のプレーヤーで聴き比べます。一方を再生すると他方は停止します。各候補のWAVも保存できます。
6. 両候補の現在の音声がそろったら、「Aを採用」「Bを採用」「同程度」「判断できない」を選び、任意の理由を入力して「評価を記録」を押します。A・Bの採用はJSON保存対象の声にも反映します。
7. 「レシピをJSONで保存」で、選択中の声と比較記録を保存します。

評価記録には日時、4軸、セリフ、両候補の調声値、判断と理由を保存します。新しい評価には、その時点のA・Bのスコア・順位、推薦ロジックとカタログの版も保存します。順位は、利用可否や画面の絞り込みに左右されないVOICEVOX全候補内の順位です。各音声の生成直後に取得できたエンジンの版と確認日時も記録し、取得できなければ「記録なし」とします。片方の音声を再利用した場合は、その音声を生成したときの情報を保持します。後から調整しても記録済みの比較条件は変わりません。比較条件を変えると、未記録の判断・理由はリセットされます。評価は最大100件です。「記録した評価を見る」で履歴を確認できます。数値はアプリ独自の提案で、評価結果も利用者による創作上の判断です。

## 複数の評価記録をまとめる

1. 画面上部の「評価記録をまとめる」を押します。AIやVOICEVOXへの接続は不要です。
2. 「現在の比較記録を追加」で作業中の評価を追加するか、「評価のJSONをまとめて読み込む」でレシピJSONや集計済みの評価JSONを選びます。作業中の声・調整値を置き換える操作ではありません。
3. 全記録の件数と判断の内訳を確認します。「評価時スコアとの関係」と「現行スコアとの関係」で、それぞれ「低スコアの候補を採用」等に絞れます。「評価時の版で絞り込む」で推薦・カタログの版を選び、理由・セリフ・候補名でも検索できます。
4. 各記録で評価時と現行のスコア・順位・スコア差を比較します。「比較条件を見る」で評価時の4軸、A・Bの調声値、推薦・カタログの版と各音声のエンジン情報、声の方向を作ったときの設定を確認します。25件ずつページを切り替えて表示します。
5. 「集計全体をJSONで保存」で後から再開できる評価JSONを保存します。「絞り込み結果をCSVで保存」は、現在の表示条件に合う全件を保存します。表示中のページだけに制限しません。

集計は最大1000件、一度の読み込みは20ファイル・合計64MBまで、各ファイルは32MBまでです。日時・4軸・セリフ・両候補の順番と調声値・結果・理由・声の方向を作ったときの設定・評価時の推薦とエンジン情報が同じ記録は重複として除きます。条件や理由が異なる評価、評価時の情報が異なる評価、情報のない旧記録は別記録として残します。同じ評価を含むファイルでカタログ確認日が違う場合は、両方の日付を保持します。不正なファイルや件数超過があると、その回に選んだファイル全体の追加を取り消し、既存の集計を保持します。

新しく保存する集計JSONは`voice-atlas-evaluations`のバージョン2です。従来の評価JSON v1も読み込めます。レシピJSONのバージョン2・3からは評価履歴だけを取り込みます。バージョン1のレシピには評価履歴がないため、追加件数は0件です。現在のカタログにない話者の評価も保持し、未収録のIDとして表示します。評価JSONの読み込みには「評価記録をまとめる」を使ってください。「レシピJSONを読み込む」は声の設定を復元する別の操作です。

評価時スコアは保存した値を表示し、現行スコアは現在のカタログと推薦式から再計算します。たとえば評価時はAが20・Bが95でも、現在はAが100・Bが60なら、A採用は評価時には「低スコアを採用」、現在は「高スコアを採用」と区別します。古いJSONに評価時の記録がなければ「記録なし」とし、現在の値で補いません。スコアには調声値の効果を含みません。スコア同点は同点として集計し、同程度・判断できない評価は高低の集計から除きます。候補が未収録の場合はスコアを補いません。取り込み元のカタログ確認日は、評価時に使ったカタログや推薦式のバージョンを確定する情報ではありません。

集計画面を閉じても集計は保持しますが、ブラウザーを再読み込みすると消えます。読み込み・集計・出力はブラウザー内で処理し、サーバーや外部サービスへ送信しません。出力にはセリフと理由を含みます。CSVには評価時・現行それぞれのスコア・順位・版、スコア差、各音声のエンジン版と確認日時、設定と演出の補足も含みます。CSVでは数式と解釈される可能性のある文字で始まるテキストにアポストロフィを付けます。JSONは元のテキストを保持します。

## 保存

### キャラクターの採用声ライブラリ

1. 「VOICEVOX・AivisSpeechを比較する」を開き、比較でAまたはBを採用した評価を記録します。比較履歴、または「製品比較の履歴を集計する」で読み込んだ評価の「採用声を登録」を押します。
2. キャラクター名・設定名（それぞれ100文字まで）とメモ（1000文字まで）を入力し、「採用声をライブラリに保存」を押します。同じキャラクターでも「通常」「戦闘」など別の設定名で複数登録できます。合計100件までです。
3. 「キャラクターの採用声ライブラリ」で名前・設定名・メモ・話者名を検索し、製品で絞れます。「登録を編集」で名前・設定名・メモを変更でき、「登録を削除」は画面内で確認してから削除します。採用時の評価・調声値・選択理由は変更しません。
4. 「候補Aに読み込む」「候補Bに読み込む」で採用声を呼び出します。指定した候補の調声値と共通セリフ、次の評価に使う4軸・キャラクター設定を戻します。もう一方の候補の設定と既存の評価は保持します。もう一方と同じ話者・スタイルになる場合は拒否します。生成済みの音声は破棄するため、再生成してください。
5. 「採用声ライブラリJSONを保存」でバックアップし、「採用声ライブラリJSONを読み込む」で追加・復元できます。専用形式は`voice-atlas-voice-library` v2（旧v1も読み込み可能）、4MiB以下です。同じID・同じ内容は重複追加せず、同じIDで内容が異なる場合、不正なJSON、100件超過は読み込み全体を取り消して既存の登録を保持します。

名前・メモ・セリフ・理由・作者のキャラクター設定、採用時の製品別調声値・取得済みのモデル情報や生成情報は、このブラウザのlocalStorageと書き出すJSONに含まれます。画像・APIキー・音声は含みません。ブラウザのサイトデータを削除すると登録も消えるため、JSONでバックアップしてください。同じPCでもホスト名やポート、ブラウザが異なると別の保存先です。保存容量が不足した場合は登録を反映せずエラーを表示します。

未導入・未接続の声も登録と読み込みは保持し、利用可否は現在の接続一覧で確認します。現在のVOICEVOXカタログから削除された話者は記録として保存できますが、比較候補への読み込みは拒否します。モデル情報は採用時の記録で、現在の利用条件は候補欄で再確認してください。従来のレシピJSON・比較セッションJSONとは別ファイルです。

### ライブラリの声を調整して別設定として保存

1. ライブラリの「候補Aに読み込む」「候補Bに読み込む」で声を呼び出すと、候補欄に派生元のキャラクター名・設定名が表示されます。導入済みの声が1つだけでも調整できます。
2. 話速・感情表現の強さなどの製品固有の調声値と、共通セリフを調整します。「候補Aの音声を生成」（BならB）で生成・試聴してください。別の候補の音声生成や、A/Bの比較評価は保存の条件ではありません。
3. 元の設定と比較する場合は「元の設定と候補Aを生成」を押します。元の調声値と調整後の調声値を、現在の共通セリフで順番に生成します。「元の設定」「調整後の設定」のプレイヤーで聴き比べられます。生成時のモデル情報はそれぞれの音声に対応する情報で、元の保存済みモデルを自動で復元する機能ではありません。
4. 「調整した声を別設定として保存」で、元と異なる新しい設定名（100文字まで）、変更理由（必須・1000文字まで）、メモ（任意・1000文字まで）を入力します。現在の調声値・セリフで生成できていれば「調整した声を別設定で保存」を押せます。生成後に調声値やセリフを変更した場合は再生成が必要です。
5. 新しい登録には調整後の値・セリフ・生成時の情報・設定と変更理由が残ります。元の採用理由・比較評価は当時のまま保持し、派生元のID・名前・設定名・調声値・セリフもコピーするため、元の登録を削除・改名しても派生元の記録を確認できます。派生した声からさらに別設定も作れます。派生した設定も合計100件の上限に含みます。

別設定の保存後はライブラリJSON v2を書き出してください。比較セッションJSONは現在の比較設定を保存しますが、調整作業の派生元は保存しません。比較セッションの復元や履歴からの比較再開後は、ライブラリから読み込み直して調整してください。旧ライブラリv1の元データは読み込み時に書き換えず、次の明示的な保存でv2になります。

### 保存した2設定を比較して使用する設定を決める

1. 「キャラクターの採用声ライブラリ」内の「保存した設定を聴き比べる」で、比較する登録A/Bを選び、「選んだ2設定で比較を開始」を押します。同じ話者・スタイルでも、異なる登録なら比較できます。同一の登録を両方には指定できません。
2. 共通セリフ（300文字まで）を入力し、「保存設定のA・Bを生成」を押します。A/Bを順番に生成し、個別に試聴・WAV保存できます。片方だけ失敗した場合は、成功した音声を保持して失敗した側だけ再試行します。個別の再生成と中止にも対応します。
3. 「保存した調声値の違い」で、同じ製品なら異なる項目とB−Aの数値差を表示します。製品が異なる場合は、各製品固有のラベル・値を並べ、数値の差分や換算は行いません。利用可否は現在の接続一覧で確認し、未導入・未接続・現行カタログ対象外の設定は生成を無効にします。
4. 両方の現在のセリフの音声を生成・試聴してから、「使用する設定を決める」でA/Bを選びます。使用場面（任意・200文字まで）、選択理由（必須・1000文字まで）を入力して「使用する保存設定を記録」を押します。最大100件で、記録成功時に比較と履歴をブラウザ内へ保存します。セリフを変更した場合は、音声を再生成するまで記録できません。
5. 履歴の「この記録で比較を再開」で、当時の2設定・セリフ・使用場面・選択と理由を呼び出せます。音声は再生成してください。履歴は25件ずつ表示します。
6. 「設定比較JSONを保存」で、編集中の比較と全記録をバックアップできます。「設定比較JSONを読み込む」は、この設定比較と履歴だけを置き換えます。不正なJSON・未対応版・不正な選択ID・100件超過・保存容量不足の場合は、現在の比較と記録を保持します。

設定比較はライブラリの登録IDで識別し、比較開始時の2登録をコピーして保持します。登録を後から編集・削除しても比較と履歴は変わりません。変更後の登録で比較したい場合は、改めて「選んだ2設定で比較を開始」を押してください。削除された登録を含む設定比較JSONも復元でき、ライブラリへの再登録は行いません。今回の試聴の生成情報・モデル情報は登録時の情報と別に記録し、取得できなかった情報は過去の値で補いません。

専用形式は`voice-atlas-library-comparison` v1、8MiB以下です。ライブラリJSON・従来の比較セッションJSONとは別ファイルです。キャラクター名・設定名・メモ・作者の設定・使用場面・選択理由と両登録の履歴を含みますが、画像・APIキー・音声は含みません。ブラウザのサイトデータを削除すると記録も消えるため、JSONでバックアップしてください。ブラウザ内の保存は記録時とJSON読み込み時で、未記録の編集内容を残したい場合はJSONを保存します。

### レシピと音声の保存

- 「WAVを保存」で生成した試聴音声を保存できます。
- 「レシピをJSONで保存」で選択中の話者、4軸、候補ごとの調声値、共通セリフ、比較する2候補、評価記録、ガイドなどを保存できます。画像・APIキー・生成音声は含みません。理由やセリフに個人情報を書いた場合はJSONにも含まれます。
- 画面上部の「レシピJSONを読み込む」で、4MB以下のJSONを復元できます。現在の作業状態を置き換えます。読み込みはブラウザー内で処理し、AIやサーバーへは送信しません。
- 新しい保存形式はバージョン3です。旧バージョン1・2も読み込めます。旧記録の評価時スコア・版情報は後から補いません。
- 未対応バージョン、不正な設定値、カタログに存在しない話者がある場合は読み込みを拒否し、作業中の状態を保持します。カタログにはあるが接続中のVOICEVOXにない候補は復元でき、「未導入」等の状態を表示して生成を無効にします。「試聴可能のみ」は保存せず、レシピ復元時に解除するため、保存した候補と設定を確認できます。
- 生成音声は復元後に再生成してください。エンジン・音声ライブラリのバージョン等が変わると、同じ数値でも音声が変わる場合があります。
- JSONはVoice Atlasの記録形式です。VOICEVOXのプロジェクトとして開く形式ではありません。

保存前に、話者の「公式情報・サンプル」「利用規約」とクレジットを確認してください。

## 作品・場面ごとのキャスティング表

1. 採用声ライブラリ内の「保存した設定を聴き比べる」で、使用する設定と理由を記録します。
2. 「作品・場面ごとのキャスティング表」で元にする比較記録を選び、作品名・キャラクター名・使用場面を入力して「キャスティングを確定して保存」を押します。
3. 同じ作品・キャラクター・場面が登録済みの場合、置き換えの確認が表示されます。確定するまで元の登録は変わりません。別の場面名なら別登録として残せます。
4. 表は作品・キャラクター・場面・設定名で検索できます。「確定設定を候補A/Bに読み込む」で、確定時の調声値と比較セリフを製品横断の比較欄に戻せます。音声は再生成してください。もう一方の候補と同じ話者・スタイルの場合や現行カタログ対象外の場合は、読み込み時にエラーを表示します。
5. 「キャスティング表JSONを保存」でバックアップできます。読み込みは既存登録に追加し、同一内容の重複は追加しません。同じIDや同じ作品・キャラクター・場面に異なる内容がある場合、全体を取り込まず現在の表を保持します。

表はブラウザ内に最大100件、JSONは8MiBまで保存できます。登録には確定元の比較記録（2つの設定、選択理由、試聴時の生成情報・取得できたモデル情報）をコピーします。ライブラリや比較履歴の編集・削除・読み込みは、確定済みの表を変更しません。取得できなかった今回の生成情報を登録時の古い情報で補うことはありません。音声ファイルは含みません。削除は各行の確認ボタンで確定します。

## 台本の作成・試聴

1. 採用声ライブラリ内のキャスティング表で「台本を作成・試聴する」を開きます。
2. 台本名を入力し、「台本に行を追加」で行を作ります。1台本20行まで、セリフは各行300文字までです。
3. 各行の「キャラクターと場面」でキャスティング表の確定設定を選び、セリフを入力します。VOICEVOXとAivisSpeechを同じ台本で使えます。割り当てた設定はコピーされ、以降の表の変更・削除には追従しません。変更後の設定を使いたい場合は、改めて声を選択してください。
4. 「未生成の行を台本順に生成」で未生成の行を順番に生成します。声の未選択・空白のセリフ・未導入・未接続・現行カタログ対象外の行がある場合は、先に修正してください。「第N行を生成/再生成」で1行だけ生成することもできます。
5. 失敗した場合は、それまでに生成した行を保持します。進捗欄から失敗行だけの再試行、または未完了対象の再開を選べます。「台本の生成を中止」や台本・ライブラリ・製品比較画面の閉鎖でも、生成済みの行は残ります。ブラウザー側の中止でエンジン内部の生成処理が直ちに停止するとは限りません。
6. 全行の音声が揃うと「台本順に連続試聴」を使えます。行の再生終了後に次の行へ進み、「台本の連続試聴を停止」で止められます。各行のプレーヤーでも個別に試聴できます。再生がブラウザーに拒否された場合は、各行の再生ボタンを使ってください。
7. 行の上下移動では、音声をその行と一緒に移動します。声・セリフの変更では、その行の音声だけを無効にします。行の追加・変更・移動・削除では連続試聴を止めます。
8. 「第N行のWAVを保存」で各行の音声を保存します。「台本をブラウザに保存」で編集中の台本を保存し、「台本JSONを保存」でバックアップできます。

台本JSONは専用のv1形式で8MiBまでです。台本名・行順・表示用セリフ・読み上げ文・割り当てた確定設定を含み、音声と今回の試聴の生成情報は含みません。再読み込み後は、同じ作品の条件が一致するブラウザ保存音声を再利用できます。JSONだけを別環境に移した場合は音声を再生成してください。ブラウザ内の台本保存は明示操作です。未保存の編集はページ再読み込みで失われます。JSON読み込みはこの台本だけを置き換え、キャスティング表・ライブラリ・比較履歴を変更しません。不正なJSON・未対応版・行ID重複・20行超過・保存容量不足では、現在の台本と音声を保持します。

## 生成の進捗・停止・再試行

台本の一括生成・変更行だけの生成・行ごとの生成を始めると、「生成の進捗・停止・再試行」に対象行の記録を表示します。成功数の進捗バーと、各行の生成中・成功・失敗・中止・未処理、試行回数、失敗理由を確認できます。「開始時の第N行」は生成を始めたときの位置で、後から行を並べ替えても同じ行を追跡します。

- **台本の生成を中止**：現在の要求を中止し、後続の生成を止めます。成功した音声は保持し、処理中だった行は中止、まだ開始していない行は未処理として残します。
- **失敗した行だけ再試行**：記録内の失敗行だけを再生成します。中止行や未処理行は含めません。
- **未完了の対象行を再開**：記録内の失敗・中止・未処理の行を、現在の台本順に生成します。成功済みの行や、元の対象外の行は生成しません。
- **生成の記録を閉じる**：進捗記録を閉じ、台本と現在の試聴音声を保持します。

例えば3行のうち第1行が成功、第2行が失敗、第3行が未処理なら、「失敗した行だけ再試行」は第2行だけを処理します。その後「未完了の対象行を再開」で第3行を処理できます。再試行中に失敗した場合も元の有効な音声を保持し、成功した行から置き換えます。既存音声の再生成に失敗した場合も、失敗行の再試行を使えます。

読み上げ文・話者・調声値が変わった行や、削除した行を含む再試行は止めます。台本側の行別生成や一括生成から対象を選び直してください。手動の読み上げ文を指定している行は、表示用セリフだけの変更なら再試行できます。未接続・未導入・接続確認中の設定では開始できません。失敗後は自動再試行せず、操作を待ちます。

記録は直前の生成だけを作業中に保持し、作品JSONやブラウザ保存には含めません。新しい生成を始めると記録を置き換えます。台本の切り替えをキャンセルした場合は保持し、実際に切り替えた場合やページ再読み込みでは解除します。台本欄を閉じると進行中の生成を中止し、再度開くと記録から再開できます。音声のブラウザ保存と再利用は別の保存操作を使ってください。

## 台本全体を1本のWAVに保存

1. 台本の全行の音声を生成します。
2. 「結合WAVの行間」に、追加する無音を0〜5000ミリ秒で指定します。既定値は300ミリ秒です。この値は台本JSON・ブラウザ保存にも含まれ、値のない旧台本は300ミリ秒で読み込みます。
3. 「台本の全行をWAVに結合」を押します。結合はブラウザー内で行い、音声生成APIを再度呼び出すことはありません。長い音声の変換・結合は画面とは別の処理で実行するため、処理中も中止ボタンを操作できます。
4. 結合音声を試聴して、「台本全体のWAVを保存」と「結合音声の出力記録JSONを保存」で保存します。2ファイルには共通の識別子を使います。

出力は48kHz・16bit PCM・モノラルです。8〜48kHzの16bit PCM、モノラル/ステレオの元音声に対応し、異なる周波数は線形補間で48kHzへ変換し、ステレオは左右を平均します。行間の追加無音は行と行の間だけに入れ、先頭・末尾には追加しません。各エンジンが生成した開始・終了無音は削除しません。この行間は結合WAVに適用され、既存の行別連続試聴の待ち時間は変更しません。

結合元の音声は合計64MiBまで、結合WAVは128MiBまでです。未対応形式・不正なWAV・上限超過の場合はエラーを表示し、行別の音声は保持します。「台本の結合を中止」または台本画面の閉鎖で結合を中止できます。台本名・セリフ・声・行順・行間・生成音声を変更すると、古い結合結果を無効にします。元の行別WAVは結合によって変わりません。

出力記録JSON（`voice-atlas-script-audio` v1）には、台本と割り当てた設定、今回の各行の生成情報・取得できたモデル情報、元音声の形式、結合後の各行の開始/終了サンプル位置・時刻、全体の長さとWAVファイル名を保存します。終了位置はその行の音声の直後を表し、行間の無音を含みません。今回取得できなかった生成情報はnullで、過去の値を補いません。出力記録は参照用で、台本読み込み用JSONとは別です。編集を再開するための台本JSONも必要に応じて保存してください。結合音声と出力記録はブラウザ内に永続保存しません。

## 台本ライブラリ

「台本を作成・試聴する」内の「作品・場面ごとの台本ライブラリ」で、最大30台本を管理できます。各台本は従来どおり20行までで、割り当てた声の設定・セリフ・行間を保存します。音声と結合結果は含みません。

1. 台本名を入力し、ライブラリ欄に作品名・場面名を入力して「台本ライブラリに保存」を押します。
2. 保存後の変更は「台本ライブラリの変更を保存」で同じ登録に反映します。作品名・場面名も変更できます。同じ名前でも別の登録IDで管理できます。
3. 一覧の「この台本を開く」で声の割り当て・セリフ・行間を呼び出します。「この保存台本を複製」は新しい登録ID・行IDと「（コピー）」付きの名前で別台本を作ります。元の台本は残ります。
4. 未保存の変更がある状態で開く・複製・新規作成・単体台本JSONの読み込みを行うと、「保存して切り替える」「保存せず切り替える」「キャンセル」を選べます。確認中は台本の編集・生成を止めます。保存に必要な名前が未入力の場合は、キャンセルして入力してください。保存に失敗した場合は、現在の編集と音声を残して確認を続けます。
5. 作品名・場面名・台本名で検索できます。削除は確認後に行い、編集中の台本は残します。編集中の登録を削除した場合、その内容は未保存の作業台本として扱います。
6. 「台本ライブラリJSONを保存」で全登録をバックアップできます。読み込みは追加方式で、登録IDと内容が同一なら追加しません。同じIDで内容が異なる場合や、形式・件数・容量が不正な場合は、全体を取り込まず現在の登録を保持します。取り込みで編集中の台本を切り替えることはありません。

ライブラリJSONは専用の`voice-atlas-script-library` v1形式、全体16MiBまでです。各台本の8MiB上限も維持します。ブラウザーの保存容量によっては、件数・ファイル上限より前に保存できなくなる場合があります。その場合も登録と編集内容は保持します。

従来の「台本をブラウザに保存」と単体台本JSONは、作業台本の保存用として引き続き使えます。ライブラリへの変更反映は別に行ってください。ページ再読み込み時には従来の作業台本を表示し、保存済みのライブラリ台本は一覧から開きます。ライブラリに未保存の変更がある場合は、作業台本を保存済みでも切り替え確認を表示します。ライブラリJSONには登録済み台本だけを含むため、編集中の変更は先に登録へ反映するか単体JSONに保存してください。切り替え後は音声を再生成します。キャンセル時には音声・結合結果を保持します。

## テキスト・CSVから台本を一括取り込み

「台本を作成・試聴する」内の「テキスト・CSVから台本を取り込む」を開きます。解析・対応付けはブラウザー内で行い、反映だけでは音声生成APIを呼び出しません。

1. テキストを貼り付けて「取り込み内容を確認」を押します。形式は1発言1行の `案内人：ようこそ。` です。半角の `:` も使えます。最初の区切り以降をセリフとして扱い、セリフ内の `12:00` などは保持します。空行は無視します。
2. CSVは入力形式をCSVにして貼り付けるか、「CSVファイルを読み込む」を使います。ファイルはUTF-8に対応します。先頭行に `キャラクター名,セリフ` の2列を指定し、列順は入れ替え可能です。カンマ・改行を含むセルは二重引用符で囲み、セル内の二重引用符は `""` と書きます。BOM・CRLFに対応し、改行はLFに揃えます。
3. 作品・場面でキャスティング表の候補を絞ります。前後の空白を除いた名前が完全一致し、候補が1件だけなら自動で対応付けます。同名候補が複数ある場合は選択してください。似た名前の推測や、未登録の声の補完は行いません。
4. 一致候補のない名前にも、絞り込み内の声を手動で割り当てられます。例えば入力の「ナレーター」に確定済みの「案内人」の声を使えます。同じ名前の行には同じ声を使います。入力した発話者名は、元の声の登録名とは別に保存します。
5. プレビューで名前・セリフを修正し、全行のエラーと未割り当てを解消します。上限は20行・各セリフ300文字・キャラクター名100文字、元入力/CSVは64KiBです。行数超過や不正なCSVは一部だけ反映せず、元入力を修正してください。プレビューの修正は元入力欄に戻しません。元入力や形式を変更すると、プレビュー・手動の声選択をやり直します。作品・場面の変更でも手動選択を解除します。
6. 台本名を付けて「確認した内容を台本に反映」を押します。既存台本を置き換え、現在の行間を引き継ぎます。未保存の変更があればライブラリ欄で保存・破棄・キャンセルを選びます。キャンセルや保存容量不足の場合、現在の台本と音声を保持します。反映後は音声を再生成してください。

未導入・未接続の声も設定として取り込めます。生成前には既存の利用可否チェックが働きます。対応付けで明示的に選んだ登録がキャスティング表から削除された場合は、別の同名候補へ勝手に置き換えず再選択を求めます。反映時に設定をコピーするため、取り込み済み台本は後の表の変更・削除に影響されません。従来の単体台本JSON、ライブラリ保存、結合音声の出力記録にも発話者名を保持します。確認中の入力・プレビュー自体は永続保存しないため、ページを再読み込みする前に台本へ反映し、必要な保存を行ってください。

## 通常・小声・緊迫などの場面別設定を呼び出す

「台本を作成・試聴する」内の「場面別の声を呼び出す」を開きます。先に、キャスティング表へ同じ作品・キャラクターの使用場面ごとの確定設定を登録してください。場面名は自由に付けられ、登録済みの話者・調声値をそのまま使います。

1. キャスティング表の作品・キャラクター・使用場面を選びます。選んだ設定の製品・話者・調声値と、現在の試聴可否を確認できます。
2. 適用する行にチェックを付けます。同じ作品に割り当てられた同名の発話者と、声が未割り当ての同名の行を表示します。別作品に割り当てられた同名人物は含めません。未割り当て行は作品が未確定なので、選んだ作品へ割り当てる行を明示的に選んでください。「対象行をすべて選択」「対象行の選択を解除」も使えます。
3. 「場面設定の適用対象を確認」で、選択した行・設定変更数・音声再生成が必要な行数を確認します。確認後に台本や登録が変わった場合は、再確認してください。
4. 「確認した場面設定を反映」で選んだ行へ設定をコピーします。表示用セリフ・読み上げ文・行順・行間は保持し、音声条件が変わった行だけを無効にします。キャンセルでは台本と音声を変更しません。
5. 必要に応じて「差し替えた行の未生成音声を生成」で変更行だけを生成します。「直前の声の差し替えを取り消す」で元の設定・保持していた音声へ戻せます。

キャスティング表と保存済み台本の元登録は変更しません。適用した結果を残すには、作品・台本・台本ライブラリの保存を行ってください。場面設定と一括差し替えは直前1回の比較・取り消し記録を共用します。未導入・未接続の設定も反映できますが、利用可能になるまで生成できません。

## キャラクターの声をまとめて差し替える

「台本を作成・試聴する」内の「キャラクターの声をまとめて差し替える」を開きます。操作対象は編集中の1台本です。

1. 発話者の一覧で行数・設定数を確認し、「差し替える発話者」を選びます。一括取り込みで発話者名がある場合はその名前、旧台本で名前がない場合は割り当てた確定設定のキャラクター名でまとめます。声も発話者名もない行は対象にできません。
2. 範囲は「この発話者の全行」か、現在使っている特定の設定を選べます。同じ話者でも調声値が異なる設定を区別します。「現在の設定・調声値を確認」で各設定の値を確認できます。未割り当ての声でも発話者名があれば、その行だけを範囲に選べます。
3. キャスティング表から差し替え先の確定設定を選び、「差し替え対象を確認」を押します。対象行のセリフ・現在の声・変更後の声と調声値、設定変更数・音声再生成が必要な行数を確認してください。
4. 「確認した声の差し替えを反映」で設定をコピーします。キャンセル時は台本・音声・結合結果を保持します。対象や台本、差し替え先の登録が変更された場合は、再確認が必要です。
5. 「差し替えた行の未生成音声を生成」で直前の差し替え対象のうち未生成の行だけを、現在の行順に生成します。ほかの未生成行は処理しません。失敗・中止後も生成済みの対象行と他の行の音声を保持し、再試行で未生成の対象行だけを処理します。従来の「未生成の行を台本順に生成」は台本全体の未生成行が対象です。

セリフ・行順・行ID・発話者名・行間は維持します。旧台本の発話者名も差し替え前の名前として保存するため、例えば案内人に騎士の声を使っても発話者は案内人のままです。ほかの発話者が同じ声を使っていても変更しません。キャスティング表・ライブラリの元登録は変更せず、結果を残すには作業台本やライブラリに明示的に保存してください。

音声条件が変わった行の音声だけを無効にします。同じ話者情報・調声値への登録情報だけの変更では音声を保持し、過去の実際の試聴情報を新しい値で補いません。設定変更後の結合音声/出力記録は作り直してください。未導入・未接続・現行カタログ対象外の設定も保存できますが、利用できる状態にするまで生成できません。直前の差し替え対象の行IDは作業中だけ保持し、台本の読み込みやページ再読み込みで解除します。

## 差し替え前後を比較し、元の声に戻す

一括差し替え、または場面設定を反映すると、「直前の差し替えを比較・取り消す」が表示されます。変更対象の行ごとに同じセリフの差し替え前・差し替え後の声、製品固有の調声値、実際の生成情報を確認できます。差し替え前に生成しておいた音声はそのまま保持します。変更後の音声を生成して、それぞれの再生ボタンで聴き比べてください。前後の音声は同時に再生しません。

「直前の声の差し替えを取り消す」で、対象行の元の設定と保持していた音声を戻します。音声生成APIへの再送信はありません。元の音声が未生成だった行は、取り消し後に生成してください。台本名・行間・行順・追加行・対象外の編集は保持し、結合WAVと出力記録は作り直します。保存済み台本やキャスティング表は変更しないため、復元した台本を残す場合は明示的に保存してください。

対象行のセリフ・声・発話者などを後から編集した場合、または削除した場合は、編集を失わないよう取り消しを無効にします。変更前の記録は確認できます。「差し替え前の記録を破棄」は現在の台本を変更せず、変更前の記録と不要になった音声を解放します。

保持するのは作業中の直前1回分です。次の一括差し替えまたは場面設定の反映、別台本の読み込み、ページ再読み込みで記録を破棄します。台本切り替えをキャンセルした場合は記録を保持します。JSONやブラウザ保存にはこの比較記録を含めません。現在の台本音声は、別の保存操作でブラウザ内に残せます。
