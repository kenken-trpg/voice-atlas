# ElevenLabs APIキー取得後の初回確認

## 1. キーの設定

リポジトリー直下の `.env` に次の項目を設定する。キーの値はチャットやコマンド引数へ貼らず、ローカルのエディターで入力する。

```dotenv
ELEVENLABS_API_KEY=取得したAPIキー
```

`.env` はGitの追跡対象外。既存の他サービスの設定はそのまま残す。起動中のVoice Atlasサーバーには再起動で反映する。

この連携が呼ぶAPIはモデル一覧、声一覧、テキスト音声合成の3種類。制限付きキーの場合はそれぞれにアクセスできるようにする。キーの権限と利用上限はElevenLabs側で設定できる。現在の設定方法は[公式のAPIキー管理](https://elevenlabs.io/docs/overview/administration/workspaces/api-keys)を参照する。

| 権限           | 設定   |
| -------------- | ------ |
| Models         | Read   |
| Voices         | Read   |
| Text to Speech | Access |

権限不足がAPI応答に示されている場合は、画面とCLIに不足する設定を表示する。`invalid_api_key` はElevenLabsによる無効判定として表示し、権限不足とは区別する。利用枠不足では残クレジットとキーの上限、同時実行数超過では他の生成の終了を案内する。不明なエラーはHTTPステータスに応じた固定文で表示し、上流の任意の本文は表示しない。

## 2. 音声を生成せずに接続確認

リポジトリー直下で実行する。

```sh
npm run probe:elevenlabs
```

モデル一覧と声一覧の最初の50件がJSONで表示される。声を探す場合は次のように検索する。

```sh
npm run probe:elevenlabs -- --search 検索語
```

この段階では音声合成APIを呼ばない。モデルの日本語対応言語情報と、使いたい声の `voiceId`、モデルの `modelId` を確認する。画面の一覧表示と同様、利用できる声・モデルは実アカウントの応答から判断する。

## 3. 画面から短い台詞を1回試聴

```sh
npm run dev
```

起動時に表示されるローカルURLを開き、製品比較のElevenLabs欄から声を検索する。モデルを明示的に選び、比較候補へ追加し、短い日本語の台詞で試聴する。ここからは台詞がElevenLabsへ送られ、アカウントの利用枠を消費する。

最初に確認する項目は、生成成功、再生可能なWAV、日本語の読み、声とモデルの表示、音声の保存。台本の配役・行別生成・一括生成にも対応する。採用声の設定比較からキャスティング表へ確定し、台本へ割り当てる。台本生成は送信確認画面で対象行・声・モデル・読み上げ文を確認してから実行する。詳しくは[台本生成の操作手順](manual.md#elevenlabsで配役した台本を生成する)を参照する。

## 4. 共通6文の実機評価

短い試聴が成功したら、取得したIDを指定して実行する。以下の `VOICE_ID` と `MODEL_ID` は実際の値に置き換える。

```sh
npm run probe:elevenlabs -- --generate --voice-id VOICE_ID --model-id MODEL_ID --output .local-artifacts/elevenlabs/run-1
```

共通評価台詞6文を送信し、WAV、待ち時間、サイズ、生成条件、失敗箇所を新しいディレクトリーに保存する。既存の出力先は使い回さず、次回は `run-2` などに変える。結果は実機評価結果の比較画面へ取り込み、待ち時間と聴取メモを記録できる。出力先の `.local-artifacts/` はGitの追跡対象外。

## 接続に失敗した場合

| 表示・症状                 | 確認すること                                                          |
| -------------------------- | --------------------------------------------------------------------- |
| APIキー未設定              | `.env` の項目名、入力後のサーバー再起動、コマンドの実行ディレクトリー |
| 認証失敗                   | 有効なAPIキーの値を設定したか、キーが無効化されていないか             |
| 利用権限なし               | キーのAPI権限、対象の声、契約プラン                                   |
| 一覧は取得できるが生成失敗 | 音声合成の権限、選択モデル・声、`pcm_22050` の利用条件                |
| 利用枠・同時実行数の上限   | ElevenLabs側の利用状況とキーの制限                                    |
| タイムアウト・上流障害     | ElevenLabs側の生成・利用状況を確認してから再実行                      |

音声生成の自動再試行はしない。実アカウントでの音質・出力形式・プラン条件の確認はキー設定後に実施する。
