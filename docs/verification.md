# 初期版の検証記録

検証日：2026-10-21。初期版（0.1.0 α）。

## 自動検証

- `npm run check`：API・ユニットテスト81件、TypeScriptの型検査、本番向けビルドが成功。
- `npm run format:check` と `git diff --check` が成功。
- 推薦・設定範囲・入力検証・画像メタデータ除去・ローカルAPI境界。
- Ollama / OpenAI / Anthropic Claude / Gemini / VOICEVOXの通信契約と、不正応答・未起動・競合処理。
- `npm run test:e2e -- --workers=2`：デスクトップ・スマートフォン相当のChromiumで48件成功。利用可否表示・候補比較・絞り込み・画像読込・送信同意・エラー表示・レシピ保存・試聴操作・画面幅を確認。
- 比較試聴は、A・Bの順次生成、候補ごとの設定・音声の保持、単独試聴との設定共有、条件変更後の音声無効化、部分失敗後の再試行、中止後の再実行を検証。
- 評価時の条件と理由が後の調整で変わらないこと、選択した声と比較記録のJSON往復、旧v1の読み込み、不正JSON・未対応バージョン・存在しない話者の拒否と作業状態の保持を検証。
- 16話者・24候補へ拡充後のカタログ参照整合性、出典・未校正状態、同じ話者の複数スタイルの独立した推薦・比較・保存復元、3種類のささやき系表記の動的スタイル照合、旧10候補のIDとJSON互換性を検証。
- 評価集計は、複数JSONの一括検証・重複排除、同一記録の確認日統合、比較条件の保持、全体JSONと絞り込みCSVの保存、再読み込み、現在の比較記録の追加、ページ切替、失敗時の集計保持、未収録IDの保持を検証。取り込み・集計操作でAPIのPOSTが発生せず、作業中の調声値が変わらないことを確認。
- スコア高低・同点と同程度・判断不可を区別し、未収録の候補にスコアを補わないこと、上限1000件、CSVの改行・引用符・数式解釈防止を検証。
- 利用可否の事前照合は、一回の話者一覧取得からスタイル別に判定し、歌唱スタイルを除外して生成時の照合と一致すること、空の正常一覧と未接続・不正一覧を区別すること、再確認で追加・削除を反映することを検証。
- ブラウザーでは「試聴可能のみ」と他条件の併用・0件からの復帰、確認中の生成停止、接続確認失敗後の古い利用可否の破棄、未導入レシピの復元、比較候補と調整値の保持、片方だけ試聴可能な場合の比較生成停止を確認。
- JSON/WAV応答のストリーム上限、Content-Length不在・偽装、本文読み取り中のタイムアウト、上限超過後の再実行、圧縮入力拒否、接続確認の同時要求共有を検証。
- ツールチップのフォーカス・Escape・ホバー・タップ操作と画面内表示、本番CSP・静的アセットのimmutableキャッシュを検証。
- 外部AIとVOICEVOXの応答はモック。有料APIは呼び出さず、モデルはダウンロードしていません。
- `npm audit --audit-level=high`：既知の脆弱性0件（以前の確認時点）。今回の比較試聴・カタログ拡充・評価集計・利用可否表示では依存関係の追加・更新はなく、監査は再実行していません。

## ローカル実行

- 本番サーバーをブラウザーテストで起動し、ホーム画面・静的ファイル・APIを検証。
- 手動モードの画面：ブラウザーのページエラーなし。
- 2026-10-20の初期画面はPC・スマートフォンのスクリーンショットを目視確認済み。今回のヘルプは自動ブラウザーテストで表示範囲・操作を確認。
- 比較試聴画面もPC・スマートフォン相当のスクリーンショットを目視確認。PCでは2列、スマートフォンでは縦並びで表示し、横方向のはみ出しがないことを確認。
- 評価集計画面もPC・スマートフォン相当のスクリーンショットで、絞り込み・集計・比較条件の表の表示を目視確認。横方向のはみ出しがないことをブラウザーテストで確認。
- 利用可否のバッジ・試聴可能件数・確認時刻・再確認ボタン・絞り込みもPC・スマートフォン相当のスクリーンショットで目視確認。横方向のはみ出しがないことをブラウザーテストで確認。
- テスト用のサーバーではローカルサービスを未接続とし、APIキーを空にしています。画像解析の品質・実際の話者の発音・音声品質の実機評価は未実施です。
- CIの短縮率はGitHubランナー上で未計測。型検査の重複、フルChromiumの取得、同じrefの古い実行、ブランチpushとPRの重複を削減する設定を追加しました。
