検証日：2026-10-21。初期版（0.1.0 α）。

## 自動検証

- `npm run check`：API・ユニットテスト58件、TypeScriptの型検査、本番向けビルドが成功。
- `npm run format:check` と `git diff --check` が成功。
- 推薦・設定範囲・入力検証・画像メタデータ除去・ローカルAPI境界。
- Ollama / OpenAI / Anthropic Claude / Gemini / VOICEVOXの通信契約と、不正応答・未起動・競合処理。
- `npm run test:e2e`：デスクトップ・スマートフォン相当のChromiumで24件成功。候補比較・絞り込み・画像読込・送信同意・エラー表示・レシピ保存・試聴操作・画面幅を確認。
- JSON/WAV応答のストリーム上限、Content-Length不在・偽装、本文読み取り中のタイムアウト、上限超過後の再実行、圧縮入力拒否、接続確認の同時要求共有を検証。
- ツールチップのフォーカス・Escape・ホバー・タップ操作と画面内表示、本番CSP・静的アセットのimmutableキャッシュを検証。
- 外部AIとVOICEVOXの応答はモック。有料APIは呼び出さず、モデルはダウンロードしていません。
- `npm audit --audit-level=high`：既知の脆弱性0件（確認時点）。

- 手動モードの画面：ブラウザーのページエラーなし。
- 2026-10-20の初期画面はPC・スマートフォンのスクリーンショットを目視確認済み。今回のヘルプは自動ブラウザーテストで表示範囲・操作を確認。
