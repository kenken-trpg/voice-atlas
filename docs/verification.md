- 評価時のスコア・VOICEVOX全候補内の順位・推薦/カタログの版を保存し、カタログのプロフィールを変更した後も過去の値が変わらず、現行スコア・順位・差分だけを再計算することを検証。

- 利用可否の事前照合は、一回の話者一覧取得からスタイル別に判定し、歌唱スタイルを除外して生成時の照合と一致すること、空の正常一覧と未接続・不正一覧を区別すること、再確認で追加・削除を反映することを検証。
- ブラウザーでは「試聴可能のみ」と他条件の併用・0件からの復帰、確認中の生成停止、接続確認失敗後の古い利用可否の破棄、未導入レシピの復元、比較候補と調整値の保持、片方だけ試聴可能な場合の比較生成停止を確認。

- ツールチップのフォーカス・Escape・ホバー・タップ操作と画面内表示、本番CSP・静的アセットのimmutableキャッシュを検証。

- `npm audit --audit-level=high`：既知の脆弱性0件（以前の確認時点）。今回の比較試聴・カタログ拡充・評価集計・利用可否表示・評価時の推薦記録では依存関係の追加・更新はなく、監査は再実行していません。

## ローカル実行

- 本番サーバーをブラウザーテストで起動し、ホーム画面・静的ファイル・APIを検証。
- 手動モードの画面：ブラウザーのページエラーなし。
- 2026-10-20の初期画面はPC・スマートフォンのスクリーンショットを目視確認済み。今回のヘルプは自動ブラウザーテストで表示範囲・操作を確認。
- 比較試聴画面もPC・スマートフォン相当のスクリーンショットを目視確認。PCでは2列、スマートフォンでは縦並びで表示し、横方向のはみ出しがないことを確認。
- 評価集計画面もPC・スマートフォン相当のスクリーンショットで、絞り込み・集計・比較条件の表の表示を目視確認。横方向のはみ出しがないことをブラウザーテストで確認。
- 利用可否のバッジ・試聴可能件数・確認時刻・再確認ボタン・絞り込みもPC・スマートフォン相当のスクリーンショットで目視確認。横方向のはみ出しがないことをブラウザーテストで確認。
- 評価時と現行のスコア・順位・差分、版別・旧記録の集計表示をPC・スマートフォン相当のスクリーンショットで目視確認。長いIDを含む未収録候補も画面幅内で折り返すことを確認。
