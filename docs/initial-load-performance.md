# 初期表示の測定

`npm run build` 後、別の端末で `PORT=3212 npm run start` を起動し、`node scripts/initial-load-probe.mjs` を実行します。空のブラウザコンテキストで各7回計測し、最初のコンテンツの描画（FCP）とDOMContentLoaded・loadの中央値、読み込んだアセットの非圧縮バイト数を出力します。デスクトップはCPU制限なし、モバイルはiPhone 13の画面設定と4倍のCPU制限です。APIは503の固定応答で、外部サービスへ接続しません。ローカル通信であり、実際のネットワーク速度や端末の性能を表すものではありません。測定中は他のテストを停止してください。

2026年10月27日のローカル測定では、接続ガイドの分割前後で初期アセットの合計は700,872バイトから696,003バイトに減りました。FCP中央値はデスクトップ84 msから92 ms、モバイル236 msから260 msでした。各7回の測定では描画時間の改善は確認できず、端末の負荷やブラウザのタイミングによる変動もあります。初回表示を高速化できたと結論づけず、今後の変更は同条件で複数回比較してください。
